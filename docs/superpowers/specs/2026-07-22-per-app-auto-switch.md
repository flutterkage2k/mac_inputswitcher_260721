# 앱별 자동 전환 — 설계 스펙

날짜: 2026-07-22
상태: 승인됨 (대화로 합의)

## 목표

지정한 앱이 활성화되면 지정한 입력소스로 자동 전환한다.
예: iTerm/터미널 활성화 → 영어(ABC). Input Source Pro의 핵심 기능 재현.

## 범위 (1차)

- **진입 시 전환만**: 규칙 앱이 활성화될 때 전환. 떠날 때 복원은 비목표 (2차 후보).
- 규칙: bundleID → (앱 이름, 입력소스 ID). UserDefaults 저장.
- UI: 설정 팝오버에 "앱별 자동 전환" 섹션 — 규칙 목록(× 삭제) +
  실행 중인 일반(regular) 앱 피커 + 입력소스 피커 + 추가 버튼.
- 전환은 기존 Switcher 경로 재사용 (CJKV 커밋, HUD, lastSwitchFailed 동일 적용).

## 감지

`NSWorkspace.didActivateApplicationNotification` (권한 불필요).

## 루프/중복 방지 (핵심 엣지)

CJKV 커밋의 포커스 사이클은 [규칙 앱 → InputSwitcher → 규칙 앱 재활성화]
순서의 활성화 이벤트를 만든다. 전환 실패 시 재활성화가 규칙을 재발동하면
무한 커밋 루프가 된다. 방어:

- 자기 자신(bundleID)의 활성화는 무시한다.
- 전환 시작 후 1초 동안은 규칙 발동을 중지한다 (시간 창 방식).
  커밋 사이클의 재활성화는 수백 ms 내에 오므로 이 창이 루프를 막는다.
  ("같은 앱 연속 무시" 방식은 Raycast가 활성화 이벤트를 만들지 않아
  [iTerm→Raycast→iTerm] 직행을 오차단하는 버그가 있어 폐기.)
- 이미 목표 소스면 전환·HUD 모두 생략.

## 비목표

앱을 떠날 때 이전 소스 복원, 앱별 "마지막 사용 소스 기억", 파일 선택창으로 앱 추가.
